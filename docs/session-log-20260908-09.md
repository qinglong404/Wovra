## 三、本轮拍板的规则与机制（全部已实现）

1. **宽限期回滚为 3 轮全豁免**（含巨轮，无事件数上限）——用户确认
   提出 3 轮时已考虑 229 步巨轮；代价知情（超水位的整理由冷却后批次
   补上）。`WOVRA_ORG_GRACE_ROUNDS`。
2. **维护路硬上限** `WOVRA_MAINT_TIMEOUT`（默认 900s）：F 组实测
   325K 大基座上整理调用深度思考细水长流 23 分钟不完成（token 在流、
   读超时不触发），且一次挂起借冷却计数堵死整条管线。到点判 failed
   解锁；维护路改**守护线程**（进程退出不被拖住）；启动/结束落
   history `maintenance` 行，挂起可观测。
3. **里程碑驱动轮 + 可见状态行**：`verify_milestone` = 轮边界
   （闭合当前轮、开新轮续写，大步 = 新步数预算）；闭合时窗口显示
   `🏁 大步『X』验收闭合——轮次 R{n} 归档`（F 组暴露的静默缺口）。
4. **步数按轮累计续上**：`steps_used` 记在 round 上随持久化，
   `\c` 续跑/进程重启都续；里程碑开新轮 = 新预算；超限按累计数报。
   （修的 bug：同一轮被打断后步数重置。）
5. **思考单行化修复**：`on_thinking` 的 nonlocal 丢了 `line_open`
   导致思考行与回答横幅贴死——已修（F 组实测抓出）。
6. **todo 大步/小步工具落地**（深度恒 1 滚动计划，人工验收两型：
   阻塞型停轮等反馈 / 非阻塞 defer_check 挂起批量呈交未决转
   experiments）。设计稿：`docs/todo-milestone-tool.md`。
7. **范围闸门首次自发生效**（F 组）：大步验收后 ask_user 给 A-F
   选项、"不自行扩大"；用户拍板终止后模型干净收尾。
   **附带发现：scope 自长 ∝ 模型速度**——"越还原越好"类无边界
   任务书在快模型上膨胀更快（F 组 15 功能域/325K 上下文）。
8. **生命周期修正**：子 agent 不会死——现世被取代只是其历史翻篇；
   **分裂是唯一结构变化**；父 agent 分裂后退化协调者。注册表
  `task.registry`（默认主 agent A）。
9. **通信原语落地**：`notify`（单向，落收件箱激活时送达）+
  `consult`（双向，切目标职责视角回答一次，回复打 `[子agent]` 标签
  直达用户窗口）。思考全局单行（`\r` 原地刷新）。

## 六、本轮方法论沉淀（可复用）

* **逐调用落账**：`llm_call` 行（prompt/cached/miss/ttft/duration/
  finish_reason）——provider 自报可信度的 TTFT 交叉验证随时可做。
* **法医三板斧**：事件时间戳重建逐调用时长 → TTL/容量拟合 → 账单
  三方对账。`d_e_forensic.py` 可对任意会话复用。
* **受控探针**：逐字节恒定前缀 × 阶梯间隔 = 缓存行为的 ground truth。
* **任务书纪律**：无边界授权（"越还原越好"）在快模型上 = scope
  自长放大器；开放目标必须配大步/验收结构。
