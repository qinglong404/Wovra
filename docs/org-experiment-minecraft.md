## 1. 协议与事故

* 三组工作区隔离（`WOVRA_WORKSPACE`/启动目录），任务书一字不差。
* 事故一：`set WOVRA_SOLO=1` 在 PowerShell 不生效（`set` 是
  Set-Variable 别名）→ A 组口径被污染重跑。修复：**chat 启动横幅
  自报组织层状态**并写入 session 记录——对照口径由运行时持有并
  当场可见，不靠用户记得设了什么。
* 事故二：用户 Ctrl+C 中断主会话，**控制台级联杀死全部后台子进程**
  （exit_code=3221225786 = 0xC000013A STATUS_CONTROL_C_EXIT）。
  修复：后台进程与 run_command 子进程加 `CREATE_NEW_PROCESS_GROUP`
  （新进程组默认免疫 Ctrl+C；整树停止走 taskkill 不受影响）。

**黑材质法医报告（像素探针实测，2026-09-08）**——结论先行：这是
**"没有眼睛"导致的缺陷，不是机制缺失，更不是大 bug，就是亮度没调
好**。取证过程本身即眼睛环的最小形态（Playwright 截图 → 像素分布 →
阈值判断）：

1. **地形在正常渲染**：Node 探针跑 mesher，单区块 21,858 顶点顶点色
   100% 非黑；页面内网格可见、MeshLambertMaterial、color 属性非零、
   四光源在、页面零报错。
2. **合成画面像素分布**：70.6% 纯黑（天空）+ 极暗地形（最亮桶仅
   rgb(127,63,63) 级）——人眼看即"全黑"，但几何与交互（射线、破坏、
   放置）全部真实工作，**漆黑中可玩**。
3. **根因一（主因）**：本地化 three.min.js（r155 时代构建，实测
   `useLegacyLights=!1`）默认物理光照模式，而模型按旧光照模型调光强
   （0.35/0.55/1.0）——全场景比设计亮度暗 π≈3.14 倍。
4. **根因二（天空）**：`scene.background` 未设置 → 清屏默认黑，占
   画面 70%。
5. **修复估计两行**（设背景色 + 光强 ×π 或开 useLegacyLights）；按
   证据纪律现场保留未修复。

**为什么 E2E 27/27 没抓住**：全部断言是行为断言（fps/顶点数/交互
链路），零像素断言——亮度问题穿透全部验证。补一条"视口中心平均
亮度 > 阈值"即可当场抓住：眼睛立项从项目级收敛为行级。

**与 A/B 的缺陷性质对比**（用户判词展开）：A 是**全部虚无**（材质
全加载不出、世界空白）；B 是**世界断断续续，断掉的部分也是虚无**；
D 的世界里**每个方块都真实存在且可交互**（挖掘/放置/飞行实绩），
只是渲染亮度错了。前两者是世界不存在，后者是世界存在但没开灯——
性质不同，修复成本不同（两行 vs 无从修起）。

## 4. 事故解剖：逻辑层账本为什么是空的

bg-4（逻辑层第二次派发）日志恰好结束在最终回答上、**没有耗时行**：
子进程 2 死于"轮已闭合、成本已记"之后、"收尾补整理"之前——即事故二

（主 agent 只好说"ST-A 还差把账本标记为 done，纯文书工作"）。
修复即事故二修复；自愈路径：重派一轮，organize_backlog 会补上历史账。

## 5. 成本归因（等效 4.6× 的构成）

1. **冷启动税 ×3**：每个子 agent 从零建上下文（读契约、重爬文件、
   缓存爬坡），命中率 73.8-94.5% vs 单 agent 98.3%，等效/步 6-10K
   vs 2.7K——最大单项；
2. **翻译与调度**：主 agent 等效 223K 只产出调度与汇报——翻译不产生
   代码但按全价计费；
3. **接缝与重复劳动**：各块自带的 mock/测试/防呆/接口适配，输出
   +1.8× 的主要来源；
4. **轮边界缓存破坏**：多轮重建装配尾部，命中率 88.1% vs 98.3%。

## 6. 四条反驳与价值主张收缩（用户，2026-09-07）

1. 主上下文不膨胀——**V3 分层装配实测已保证**（A 组 90K 封顶从未
   失控），多 agent 增量为零；它多给的只有"专项 agent 手里是自己
   块的全分辨率"，对调度的脑没意义；
2. 并行——市面 commodity；
3. 交叉验证——有明确验收标准 + 独立审查轮即可大部分替代；
4. 失败隔离——V3 降档本来就在做"无关话题淡化"。

**收缩后组织层的独占资产只剩三项**：账本=报告 + 编制复用（长周期
记忆与连续性，V2 蓝本未建未证）、升级/拍板/待办实验的人机协同通道
（已小规模实证）、父驱动里程碑循环（已跑通第一圈）。

**步数预算的裁决**：15 步硬预算方案被否——数据实证多小轮命中率
69.8%（主 agent 6 小轮）vs 98.3%（大轮），预算税（轮边界重建
×2.7）不划算。改为**里程碑驱动轮**：轮长由父 agent 派发时写明的
检查点定义（"本轮做到 X 可验证就收尾"），步数上限退化为安全网。
